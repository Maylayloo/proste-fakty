## Running

```bash
docker compose up -d --build postgres qdrant backend
```

API docs: http://localhost:8000/docs

## Seed data

`db/seed.sql` is a dump of the `sittings` table, including descriptions generated by Gemini. Postgres loads it
on the first start (empty volume), so the project works without a `GEMINI_API_KEY`.

```bash
./db/dump.sh               # refresh the dump from the running database, then commit db/seed.sql
docker compose down -v     # drop the local database; the next `up` loads the dump again
```
